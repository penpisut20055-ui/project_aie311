# MANIFEST CHAT AI — Group Portfolio & AI Assistant

เว็บแอปพลิเคชันแสดง Portfolio ของกลุ่ม **MANIFEST** (แนวคิด: "ฝันให้ไกล ไปให้พ้น") พร้อมระบบแชต AI ที่สามารถตอบคำถามเกี่ยวกับผลงานและทักษะของสมาชิกในกลุ่มจากฐานข้อมูลจริง

## สมาชิกในกลุ่ม MANIFEST
1. **เตชิน เดชจิตร** — Frontend & UI/UX 
2. **จารุยา จรุงพร** — Backend & Database 
3. **เพ็ญพิศุทธิ์ วชิระอารีรัตน์** — AI Integration

## Tech Stack
- **Frontend:** React (Vite)
- **Backend:** Node.js, Express
- **Database:** PostgreSQL
- **AI Integration:** Google Gemini API (`@google/genai`)
